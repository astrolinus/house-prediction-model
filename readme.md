# California Housing Price Prediction Model

This project implements an end-to-end Machine Learning pipeline to predict median house values in California using the `housing.csv` dataset.

---

## 📊 Dataset Overview

The dataset contains metrics from the 1990 California census:

- `longitude` & `latitude`: Geographic coordinates of the block group.
- `housing_median_age`: Median age of houses within the block.
- `total_rooms` & `total_bedrooms`: Total number of rooms and bedrooms.
- `population` & `households`: Total occupants and households.
- `median_income`: Median household income in tens of thousands of USD.
- `ocean_proximity`: Proximity to the coast (`<1H OCEAN`, `INLAND`, `NEAR OCEAN`, `NEAR BAY`, `ISLAND`).
- `median_house_value`: Target variable — median house value (in USD).
